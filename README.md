# 한국 귀신 인터랙티브 · 전시 통합 사이트

손각시·몽달귀신, 고관대면, 창귀, 귀신의 전화, 화면 속에만 있는 사람, 금지된 방송을 한 메뉴에서 선택해 실행하는 정적 웹사이트입니다. 기존 작품의 장면과 인터랙션을 보존하고, 새 통합 메뉴와 공용 AI 모델 경로만 추가했습니다.

## 실행

**공개 전시 실행: https://jinwoon-bot.github.io/ghost-exhibitions/**

GitHub 로그인 없이 누구나 열 수 있습니다. 2026-11-24에 배포 성공, 메인과 6개 작품의 브라우저 진입, 인증 헤더/쿠키 없는 공개 파일 301개 GET·해시 일치를 확인했습니다. GitHub 저장소 화면과 전시 실행 화면은 서로 다릅니다.

메뉴에서 작품을 선택하고, 작품 안의 시작 버튼을 누르세요. 카메라 작품은 사용자가 권한을 허용해야 실제 입력이 연결됩니다. 전시 목록으로 돌아오면 이전 작품의 프레임을 제거하므로 카메라와 음원이 다음 작품과 겹치지 않습니다. 오디오 작품은 브라우저/운영체제 출력 장치를 확인하세요.

다른 PC에서는 프로그램 설치 없이 최신 Chrome으로 공개 HTTPS 주소를 열 수 있습니다. 카메라 종류·해상도·조도·의자 영역·음량은 현장에 맞춰 다시 조정해야 합니다. 링크 접속 검사는 실제 다른 PC의 인식 정확도나 장시간 운영 검사를 대신하지 않습니다. 모바일은 메뉴·일부 미리보기용이며 전시는 PC Chrome을 권장합니다.

## 포함한 작품

| 작품 | 상호작용 |
| --- | --- |
| 손각시 · 몽달귀신 | 착석 → 걷기 → 얼굴 공개 |
| 고관대면 | 가까운 관객의 좌우 위치를 눈동자로 응시 |
| 창귀 | 움직임의 잔상이 한지/먹으로 흩어짐 |
| 귀신의 전화 | 화면 버튼·3.5mm 수화기 출력과 83편 음원 |
| 화면 속에만 있는 사람 | 고개 방향에 반응하는 화면 속 존재 |
| 금지된 방송 | 접근·손동작에 반응하는 지역방송 |

고관대면 카드의 **귀면 도깨비 열기**는 통일신라 귀면무늬를 바탕으로 만든 별도 그림 시연입니다. 도깨비의 눈동자가 한 관객을 따라갑니다. [귀면 도깨비 실행](https://jinwoon-bot.github.io/ghost-exhibitions/works/dokkaebi/) · [그림과 조작 안내](docs/DOKKAEBI.md)

실사 캐릭터와 음원은 기존 제작물을 재사용합니다. 새 뉴스 6초 MP4는 별도 미리보기 링크로만 넣었으며 기존 방송 앱의 장면을 교체하지 않았습니다. 소품 전화기는 별도 센서가 없으면 들기/내리기를 자동 감지하지 못합니다.

## 구조

`site/index.html`은 통합 메뉴, `site/works/`는 여섯 실행본, `site/shared/mediapipe/`는 바이트 해시가 같은 모델·JS·WASM의 공용 사본입니다. 창귀의 서로 다른 TensorFlow/BodyPix 모델은 그대로 보존했습니다. 필요한 작품만 로드하며 메뉴에서는 AI 모델을 미리 내려받지 않습니다.

제작 원본, 백업, 개인 관객 영상, API 키, PIN, 토큰, Python/Godot 실행기는 공개 사이트에 포함하지 않습니다. 각 작품의 라이선스와 출처 고지는 유지합니다. 일부 기존 ElevenLabs 음원에는 비상업적 이용·출처 표시 조건이 있습니다. 공개 접근을 허용한다는 것과 모든 에셋에 자유로운 상업 이용 권리가 있다는 것은 다릅니다.

## GitHub Pages

새 공개 저장소의 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다. `.github/workflows/pages.yml`은 `site/`만 게시합니다. Node는 CI 검사에만 사용하며 방문자의 PC에 설치할 필요가 없습니다. 외부 백엔드 없이 동봉 에셋·모델로 기본 전시를 실행합니다. 기존 전화 음성 제작 스튜디오의 추가 생성은 공개 전시 재생과 별개입니다.

개발자가 이 폴더에서 `node tools/check-site.mjs`로 파일·문법·상대경로를 검사하고, `node tools/serve.mjs`로 로컬 미리보기를 열 수 있습니다. 원본 계정과 교수님 저장소는 수정하지 않았습니다.

## 검증 기록

- `docs/STATIC_VALIDATION.json`: 정적 파일·문법·링크 검사.
- `docs/MODEL_VALIDATION.json`: 네 작품의 공용 모델을 Worker에서 실제 실행한 검은 프레임 시험. 실제 카메라 시험이 아닙니다.
- `docs/MIGRATION.json`: 복사와 공용화의 근거.
- `docs/SITE_ASSETS.json`: 배포 파일 크기·SHA-256.
- `docs/REFERENCE_REVIEW.md`: 교수님 구현에서 참고한 방식과 차이.

공개 배포·접속 검증 결과는 별도 `docs/DEPLOYMENT.json`에 남깁니다. 검사하지 않은 환경을 완료로 표시하지 않습니다.
