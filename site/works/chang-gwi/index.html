움직임은 지나가고,
형상은 그 자리에 남는다.

카메라 권한을 한 번 허용하면 관객은 조작 없이 참여합니다.
영상은 이 기기 안에서만 처리되며 저장되지 않습니다.

Chrome에서 열고 카메라를 허용하세요. USB 카메라는 위 목록 또는 운영 설정에서 선택할 수 있습니다.

D 운영자 패널 · F 전체화면

카메라가 열리지 않을 때

전시 실행은 일반 Chrome을 권장합니다. 카메라 접근이 거부되면 Chrome 주소 왼쪽 사이트 설정에서 카메라를 허용한 뒤 다시 연결하세요. Windows 설정 → 개인정보 및 보안 → 카메라에서도 Chrome의 접근을 확인하세요. 다른 카메라 앱이 사용 중이면 종료한 뒤 다시 연결하세요.

영상이 먼저 표시되고 인물 분리는 잠시 뒤 준비됩니다. 연결된 카메라가 없으면 샘플 영상으로 바뀌지 않으며 오류를 표시합니다.
