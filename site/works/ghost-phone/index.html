VOICE LIBRARY 귀신별 데이터 설정

Multilingual v2는 자유로운 스타일 지시 프롬프트를 지원하지 않습니다. 해당 모델은 목소리 선택·속도·안정성으로 조절하며, 스타일 메모를 읽어 주지 않습니다. 지시를 전달하는 별도 게이트웨이는 서버 어댑터로 연결합니다.

가져온 파일은 이 탭에서만 사용됩니다. 다른 PC로 옮길 때 프로젝트 assets/audio에 넣고 경로를 등록하세요.

AI 대사를 바꾼 뒤에는 내보낸 설정으로 백엔드 허용 목록도 배포해야 합니다. 브라우저의 임의 대사·모델은 서버가 실행하지 않습니다.

AUDIO & HARDWARE 연결은 실제 결과로 확인

브라우저 TTS에는 필터·별도 출력이 적용되지 않습니다. 수치 제한은 실제 귀에 닿는 음압을 보장하지 않으므로, 현장에서 낮은 시스템 음량부터 조정하세요.

이 토큰은 현재 탭의 메모리에만 있습니다. 공급자 API 키는 Cloudflare 비밀 환경변수로만 등록합니다.
