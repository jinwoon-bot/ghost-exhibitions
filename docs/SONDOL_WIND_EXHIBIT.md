# 손돌바람 · 전시 운영과 모션 소스

## 장면

강화와 김포 사이의 손돌목에서 전해지는 설화에는 험한 물길을 건너던 뱃사공 손돌이 억울하게 죽고, 그의 넋을 달래는 제사와 음력 시월의 찬바람이 이어집니다. 작품은 이 전승을 바탕으로 한 창작입니다. 관객의 숨이 폭풍을 일으키고, 사라졌던 뱃사공과 마주친 뒤 다른 배가 나타나는 순환은 작품의 연출입니다. [국립민속박물관 〈손돌제〉](https://folkency.nfm.go.kr/topic/detail/2410) · [한국학중앙연구원 〈손돌목〉](https://encykorea.aks.ac.kr/Article/E0030488) · [김포문화원 〈손돌목〉](https://gimpomunhwa.or.kr/html/site/gimpo/munhwa/18th/story02.html)

## 22초 소스 시연

| 시점 | 연출 |
| --- | --- |
| 00:00–00:02 | 수평선 가까이 나룻배가 떠 있고 낮은 물결과 밤바다 소리가 이어집니다. |
| 00:02–00:06 | 물결이 높아지고, 배가 뒤로 밀려갑니다. 앞물결이 올라오며 배를 가리고 마지막 물보라가 흩어집니다. |
| 00:06.64–00:09.64 | 원본 믹스의 모든 샘플을 0으로 내린 3초입니다. 화면에는 어두운 수면만 보입니다. |
| 00:09–00:14 | 손이 수면을 가른 뒤 검지부터 손가락이 차례로 조금 오므라듭니다. 이어 깊게 꺼진 눈구멍과 한쪽에 남은 눈이 어둠에서 드러납니다. |
| 00:14–00:18 | 손돌은 정면을 응시하면서 고개가 아주 미세하게 기울었다 돌아옵니다. 머리카락 몇 가닥이 그 움직임보다 늦게 밀립니다. 턱에서 떨어진 물방울은 수면을 건드려 잔물결을 만들고, 그 순간에 맞춰 소리가 납니다. |
| 00:18–00:22 | 손돌이 물속으로 가라앉습니다. 잔잔해진 수평선의 다른 위치에 반대 방향의 배가 보입니다. |

22초 시연은 합성 연출을 검토할 때 사용합니다. 전시판에서는 바다가 입력을 기다립니다. 짧은 바람이 끝나면 수면이 잦아들고, 바람이 충분히 쌓이면 배가 사라집니다. 그 뒤 약 3초간 정적이 이어지고 손, 손돌의 응시, 물방울, 새 배가 차례로 나타납니다.

시연은 1920×1080, 24 FPS MP4로 렌더링했습니다. 물방울 GIF의 프레임을 움직이는 턱과 수면 사이에 합성합니다. 원혼과 손은 소스 PNG에 GIF와 같은 움직임을 적용해 색과 가장자리의 디테일을 살렸습니다. 효과음은 별도 제작한 합성 파형입니다.

소스 ZIP에는 `render-look.py`와 `sondol_motion.py`가 포함됩니다. 재렌더링에는 Blender 4.5와 Blender의 Python 3.11에서 불러올 수 있는 Pillow가 필요합니다. Pillow를 프로젝트 폴더에 설치했으면 `SONDOL_PILLOW_PATH`에 그 경로를 지정합니다. ZIP을 푼 폴더에서 `blender.exe -b -t 4 --factory-startup --python render-look.py -- assets sondol-look.mp4 frames`를 실행합니다. 프레임과 믹스는 `frames`에 생성됩니다.

## 전시 PC에서 실행

통합 전시 목록의 여덟 번째 카드에서 손돌바람을 열 수 있습니다. [공개 전시 실행](https://jinwoon-bot.github.io/ghost-exhibitions/works/sondol-wind/)

로컬에서 실행할 때는 아래 순서대로 진행합니다.

1. 전시 ZIP을 풀고 해당 폴더에서 터미널을 열어 `node tools/serve.mjs`를 실행합니다. 실행 중에는 터미널 창을 열어 둡니다.
2. Chrome 또는 Edge에서 [손돌바람 로컬 실행](http://127.0.0.1:4387/ghost-exhibitions/works/sondol-wind/)을 엽니다. 마이크 접근과 모듈 로딩에는 로컬 서버 또는 HTTPS가 필요합니다.
3. **전시 시작**을 누르고 해당 로컬 사이트의 마이크 접근을 허용합니다. 처음 1~2초 동안 마이크 주변을 조용히 유지하면 초기 소음 기준을 잡을 수 있습니다.
4. **D**로 운영실을 열어 마이크를 선택하고 입력 미터를 확인합니다. 전시장 소음이 달라졌으면 **소음 재측정**을 누르고, 관객 위치에서 마이크와 15~25cm 거리를 두고 불어보며 민감도와 최소 지속 시간을 맞춥니다.
5. **F**로 전시 화면을 전체 화면으로 전환합니다. 브라우저 내장 보기에서 전환이 제한되면 Chrome 또는 Edge의 **F11**을 사용합니다.

마이크가 없는 시연에서는 **키보드 시연**을 선택하고 **Space**를 약 8초 길게 누릅니다. 키를 누르는 동안 약·중·강 순으로 바람이 커집니다. 짧게 눌렀다 떼면 배와 물결이 서서히 잦아듭니다. 운영실에는 바람 단계가 표시되며 수동 바람, 폭풍, 배 소실, 손, 원혼을 따로 점검할 수 있습니다. 운영실을 닫으면 수동 바람 값이 초기화됩니다.

수면과 배는 실시간으로 계산합니다. 달과 높은 하늘을 기준으로 먼 산은 천천히 왼쪽으로, 물결은 오른쪽으로 흐릅니다. 원경 잔물결, 중경 파도, 전경 너울의 기본 이동 속도 비율은 1:2:4입니다. 약풍은 잔물결과 가까운 바람 소리를 키우고 중풍은 너울과 배의 흔들림을 키웁니다. 강풍이 일정 시간 누적되면 배가 사라집니다. 배가 사라진 뒤 약 3초 정적이 이어지고, 손가락과 손돌을 투명 소스로 실시간 합성합니다. 손돌이 수면 위로 올라오는 데 약 5초 걸리며 그동안 배경도 흐릅니다. WebGL을 쓸 수 없거나 프레임이 떨어지면 같은 깊이별 움직임을 Canvas 2D로 렌더링합니다. 마이크 신호는 브라우저에서 바람 강도로 분석하며 저장하거나 전송하지 않습니다. 브라우저에는 운영 설정을 저장합니다.
