# 귀신의 전화 · 점진적 변조

통합 전시의 귀신의 전화를 열면 창귀 〈길 건너편〉이 기본 MP3 전시 통화로 재생된다. **장비 없이 한 통화 듣기 → 수화기 들기**로 같은 연출을 시연할 수 있다. 같은 화면에서 **이전 전시판**을 열면 기존 통화 편성을 실행할 수 있다. **음원 보관함**의 기존 83편과 MP3·AI·브라우저 시험 모드는 유지한다.

## 운영과 비교 청취

- `D`로 운영실을 열고 **체험 시험 → 점진적 변조**에서 기본 통화 여부, 대표 통화, 최대 강도, 시작 초, 진행 속도, 잡음과 최종 음량을 조절한다. 저장된 설정은 다음 통화부터 적용된다. 기본 시작은 7초다.
- **창귀 변조 비교**에서 같은 원음과 음량으로 A 고정 강변조, B 점진적 변조, C 마지막 변조를 들을 수 있다. A는 새 대사에 고정 강변조를 적용한 비교다. 과거 창귀 후보정 파일은 별도로 음원 보관함에서 들을 수 있다.
- 물리 수화기 감지는 기존 USB 센서 입력을 사용한다. 3.5mm 단자는 음성 출력에 사용한다. USB 센서가 없는 수화기는 화면의 수화기 버튼이나 운영실의 가상 센서로 연결과 종료를 제어한다.
- 원음과 연기 지시, 출처는 [새 창귀 원음 기록](../site/works/ghost-phone/assets/audio/progressive/SOURCE.md)에 있다.

## 검증 범위

Chrome 로컬 시험에서 동일 소스의 A/B/C 재생, 중간 중단, 이어지는 새 통화, 상대방 종료, 운영실에서의 기본 통화 선택, 이전판 재생을 확인했다. 가상 수화기를 내려놓은 뒤 81ms 이내에 재생 종료를 관측했다. 이 값은 브라우저 이벤트 폴링 간격을 포함하며 실제 USB 센서 지연을 포함하지 않는다.

기본 B 렌더에서 첫 7초는 전화선 필터만 적용했고 18.54초의 마지막 문장 시작 시 변조 강도는 약 1.0이었다. 출력 최대값은 -8.23dBFS였다. 청음에서는 첫 문장의 자연스러움, 마지막 문장의 명료도, 실제 수화기 출력의 잡음과 음량을 확인해야 한다.
