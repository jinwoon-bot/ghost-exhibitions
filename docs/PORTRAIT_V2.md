# 〈당신을 보는 영정〉 · V2 전시 운영

## 작품

오래된 한국식 영정사진의 두 눈이 관객 한 명을 따라갑니다. 관객이 멈추면 응시도 멈춥니다. 화면에서 사라지면 마지막 시선을 1초간 유지한 뒤 정면으로 돌아옵니다. 얼굴, 눈꺼풀, 입, 관모, 몸과 구도는 고정됩니다.

가상 인물의 실사풍 합성 사진을 사용했습니다. 승인된 고관대면 시트의 나이 든 얼굴, 무표정, 어두운 전통 복식을 참고하고 눈이 더 잘 읽히도록 관모와 구도를 조정했습니다. 생성 원본은 1086×1448이며, 화면용 WebP는 3072×4096으로 확대했습니다. 확대본의 세로 픽셀 수가 원본의 디테일을 늘리지는 않습니다. 기존 초상 에셋은 프로젝트에 보존했습니다.

정면은 초상 원본 그대로 표시합니다. 시선이 움직일 때 양쪽 눈꺼풀 안쪽에 한해 초상의 홍채와 동공 텍스처를 좌우로 보간합니다. 양쪽 눈은 같은 관객의 좌표를 사용합니다. 화면 전체 애니메이션과 눈 깜빡임은 사용하지 않습니다. 소리는 기본으로 꺼져 있습니다.

## 실행

통합 GitHub Pages에 게시된 뒤에는 Windows의 Chrome에서 전시 메뉴를 열고 **당신을 보는 영정 → 전시 시작 → 카메라 허용**을 선택합니다. GitHub Pages의 공개 주소에는 방문자용 개발 도구 설치가 필요 없습니다.

검토용 작업 폴더에서 열 때는 통합 저장소 최상위에서 `node tools/serve.mjs`를 실행하고 Chrome에서 `http://127.0.0.1:4387/ghost-exhibitions/works/portrait/`를 엽니다. 로컬 서버에는 Node가 필요합니다. 작업 폴더를 `file://`로 열면 카메라가 시작되지 않습니다. 얼굴·전신 인식 파일은 사이트에 포함되어 있으므로 같은 서버로 제공됩니다.

- **D** 운영 설정 열기 또는 닫기
- **F** 전체화면 전환
- **R** 시선 정면 초기화
- **마우스 시연** 카메라 없이 화면을 좌우로 움직여 눈을 시험합니다.

## 전시 설치 및 조정

1. 카메라를 모니터 중앙에 가깝게 두고 관객의 얼굴 또는 상체가 좌우 끝에서도 들어오도록 맞춥니다. 정면에 강한 역광이 있다면 관객 쪽에 약한 확산광을 확보합니다.
2. D의 운영 화면에서 카메라를 선택하고 재연결합니다. 관객이 실제로 설 중앙에 선 다음 **현재 관객을 중앙 기준으로** 버튼을 누릅니다. 관객이 화면 오른쪽으로 이동했을 때 눈이 반대로 움직이면 좌우 방향을 바꿉니다.
3. 가까운 한 명 선택이 기본이며 얼굴 또는 몸통의 화면상 크기를 거리의 근사값으로 씁니다. 여러 사람이 비슷한 거리에 서는 공간이라면 **중앙에 있는 한 명**을 선택할 수 있습니다. 대상이 계속 바뀌면 전환 전 대기 시간을 늘립니다.
4. 기본 시선 이동 폭은 원본 좌표 8px입니다. 현장에서 시선이 지나치게 작아 보이면 이동 폭을 올리고, 빠른 움직임에 뒤처지면 반응 시간을 낮춥니다. 인식 속도가 떨어지면 먼저 한 명만 시야에 둔 상태에서 동작을 확인하고 분석 빈도를 조정합니다.
5. 운영 확인 뒤 카메라 추적 정보를 끄고 패널을 닫습니다. F 전체화면에서 운영 화면과 포인터가 숨겨집니다.

Chrome이 권한을 거부하면 주소창 왼쪽의 사이트 권한에서 카메라를 허용하고 D의 재연결 버튼을 누릅니다. 기기를 열 수 없으면 카메라를 사용하는 다른 앱을 닫고 기본 카메라를 선택해 다시 연결합니다. 화면의 오류 안내는 카메라 입력과 마우스 시연을 구분해 표시합니다.

카메라 프레임은 브라우저 내부에서 처리합니다. 관객 사진과 영상은 저장하거나 전송하지 않습니다. 카메라 선택과 보정값은 해당 브라우저에만 저장합니다. 운영자가 내려받는 수치 보고서에는 처리 시간과 집계된 검출 횟수만 남습니다.

## 검증

- `node --test tools/test-portrait.mjs` 4개 통과. 30·60·144FPS 시간 간격에서 정지·유지·복귀를 확인했고, 다인 후보가 지속될 때만 대상이 바뀌는지와 눈 양끝의 고정점을 검사했습니다.
- Windows Chrome의 1920×1080 렌더를 비교했습니다. 왼쪽으로 응시할 때 눈 영역 내 변경은 461px과 420px, 오른쪽은 471px과 413px이었습니다. 두 눈 캔버스 바깥 변경은 0px이었습니다. 시선 정지, 관객 이탈 직후 방향 유지, 정면 복귀 후에도 각 기준과 픽셀이 일치했습니다.
- Chrome 3840×2160 출력과 412×797 화면에서 액자 배치와 세로 사진 비율을 확인했고, F 전체화면 전환을 시험했습니다. 실제 행사장 모니터의 시청거리와 밝기 시험은 남아 있습니다.
- 브라우저 내부에서 만든 이동 인물 영상으로 실제 Face/Pose 모델 실행, 얼굴 인식, 좌우 반전, 대상 이탈 후 0.000 복귀를 확인했습니다. 한 사람이 좌우로 움직이는 동안 다른 관객으로 전환한 횟수는 0회였습니다. 첫 프레임 분석을 마친 뒤 작품을 표시하더라도 시작 구간을 포함한 측정에는 최대 268.8ms 프레임 간격이 있었습니다. 이후 시험 구간의 최대는 17.1ms였습니다. 이 수치는 하드웨어 카메라의 추론 성능을 나타내지 않습니다.
- 통합 사이트 6개 작품, 정적 파일 310개, 스크립트 92개, HTML 링크 48개와 공용 모델 상대경로를 점검했습니다. 이번 회차의 직접 시연은 마우스 모드로 진행해 실제 웹캠 입력, 전시 PC의 저조도 다인 추적과 장시간 구동은 미검증입니다.
