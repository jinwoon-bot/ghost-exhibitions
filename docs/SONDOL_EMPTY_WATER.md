# 손돌바람 · 빈 물길

관객이 바람을 불면 밤 물길이 거칠어지고, 수면 한곳이 물밑에서 밀리는 듯 솟습니다. 물방울이 렌즈에 붙으면 그 안쪽의 풍경이 굴절되고, 물방울은 천천히 흘러내립니다. 강풍이 계속되면 나룻배가 파도에 가려 사라집니다. 폭풍이 멀어지는 동안 수평선의 안개가 짙어지고, 빈 수면에 나룻배가 남겼을 법한 항적이 가까워집니다. 잠긴 나무가 삐걱거리는 소리가 수면 아래를 건너갑니다. 이후 안개와 항적이 사라지고 다른 배가 나타납니다.

## 실행

공개 전시 목록의 손돌바람 카드에서 **빈 물길판 열기**를 선택합니다. [빈 물길판 실행](https://jinwoon-bot.github.io/ghost-exhibitions/works/sondol-wind-empty-water/)

1. 로컬에서 실행할 때는 Node.js가 설치된 컴퓨터의 저장소 폴더에서 `node tools/serve.mjs`를 실행합니다.
2. [손돌바람 · 빈 물길 로컬 실행](http://127.0.0.1:4387/ghost-exhibitions/works/sondol-wind-empty-water/)을 브라우저에서 엽니다.
3. **전시 시작**을 눌러 마이크를 사용하거나 **키보드 시연**에서 **Space**를 약 7초간 누릅니다.
4. **D**에서 장치, 감도, 음량, 저사양 모드를 조정합니다. **F**로 전체 화면을 전환합니다.

수면, 나룻배, 물안개를 실시간 합성합니다. 음향은 기존 밤 물길 음원과 이를 변형한 수중 잔향을 사용합니다. 마이크 신호는 브라우저에서 강도만 분석하며 저장하거나 전송하지 않습니다.

자동 검사는 `node tools/test-sondol-empty-water.mjs`로 실행합니다. 실제 전시장 마이크 감도와 스피커 음량은 설치 장비에서 확인해야 합니다.
